# 로직 구조 결정 (1단계)

## 1. 결과 확정은 `SlotLogic.spin()` 한 곳에서
- **선택:** `spin()`이 정지 위치를 추첨하고 즉시 `resolve_stops()`로 판정·피버·풀까지 확정해 `SpinResult`로 돌려준다. 화면은 이 결과를 보여주기만 한다.
- **이유:** 기획서의 "결과 조작 금지" 규칙을 구조로 보장한다. STOP 타이밍이 결과에 끼어들 틈이 없다.
- **다른 후보:** 릴이 멈출 때마다 판정 → 연출 타이밍과 결과가 섞일 위험이 있어 제외.

## 2. 풀 금액은 정수 × 10000으로 보관
- **선택:** 내부에서는 풀 × 10000을 정수로 들고 있고, 표시·지급할 때만 정수로 버림한다.
- **이유:** 8 × 5% = 0.4처럼 소수점이 생기는데, 실수(float)로 오래 더하면 오차가 쌓인다.
- **다른 후보:** 실수 누적(오차), 매 스핀 버림(BET 8에서 0.4가 매번 0이 되어 풀이 안 쌓임).

## 3. 판정 테스트는 전용 데이터 사용
- **선택:** `logic_test`는 코드 안에 작은 테스트용 데이터를 만들어 쓴다.
- **이유:** 밸런스 조정으로 `balance.json`을 바꿔도 규칙 테스트가 깨지지 않는다.
