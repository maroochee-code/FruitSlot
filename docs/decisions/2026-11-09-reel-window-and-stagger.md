# 릴 연출: 칸 단위 클리핑 창 + 릴별 출발 시간차·속도차

## 고른 것
1. **칸마다 창(Control, clip) 9개를 고정**하고, 창 하나에 심볼 칸 2개(위/아래)를 넣어 스크롤한다. 두 칸은 창 높이만큼 붙어 있어서(칸 사이 간격 없음) 위 심볼 아랫부분 + 아래 심볼 윗부분이 반쪽씩 보인다.
2. `half_row`(위아래 덤 영역) **삭제**. 덤 영역과 어두운 가림막이 필요 없어졌다.
3. `reel_start_delay`, `reel_speed_scale`을 `feel.json`에 릴 3개짜리 목록으로 추가. 기본값은 시간차 [0, 0.08, 0.16]초, 속도차 [1.0, 0.95, 1.05] (속도차가 처음부터 보이도록 사용자가 지정).
4. 자동 정지 시각은 **계속 START 기준**. 출발 지연은 늦게 출발하는 릴의 회전 시간만 줄인다.
5. 출발 전 릴은 STOP을 받지 않고, 회전 중 START는 출발 전 릴도 같은 순서로 예약해 출발 직후 멈추게 한다.
6. 출발 지연이 `auto_stop_start` 이상이면 지연 목록을 기본값(그래도 안 맞으면 0)으로 돌린다.

## 다른 후보
- `half_row`를 남기고 무시: 효과 없는 수치가 남아 혼란.
- 자동 정지를 "각 릴 출발 시각 기준"으로: 회전 시간은 같아지지만 값이 서로 얽혀 손맛 조절이 어렵다.
- 심볼마다 따로 마스크(shader) 처리: 이 규모에서는 Control의 `clip_contents`로 충분.

## 이유
- 결과 확정 로직(START 때 RNG로 한 번)은 그대로이고, 보이는 심볼은 항상 스트립 순서라서 "결과 불변" 규칙이 유지된다.
- 수치는 모두 `data/feel.json`에서 읽는다(수치 하드코딩 금지).
