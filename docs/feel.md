# 손맛 조절 안내 (`data/feel.json`)

릴이 돌고 멈추는 느낌을 바꾸는 수치 모음입니다. 파일을 고치고 게임을 다시 실행(F5)하면 바로 적용됩니다.
**결과(어떤 심볼이 서는지)는 이 수치와 무관합니다.** 결과는 START 순간에 정해지고, 이 수치는 "어떻게 보여주느냐"만 바꿉니다.

범위를 벗어나거나 숫자가 아닌 값을 넣으면 그 항목만 기본값으로 대체되고, 실행 로그에 경고가 남습니다. 게임이 꺼지지는 않습니다.
`reel_start_delay`·`reel_speed_scale`은 릴 3개 분량의 목록(`[릴1, 릴2, 릴3]`)입니다. 개수가 다르거나 하나라도 범위 밖이면 목록 전체가 기본값으로 대체됩니다.
(예전 `half_row` 항목은 칸 단위 창 방식으로 바뀌며 없어졌습니다. 파일에 남아 있어도 무시됩니다.)

| 키 | 기본값 | 범위 | 올리면 / 내리면 |
|---|---|---|---|
| `spin_speed` | 26 | 1~200 | 칸/초. 올리면 빨리 돌고, STOP 후 멈추기까지의 최대 대기도 짧아집니다. 너무 높으면 심볼이 번쩍거려 읽기 어렵습니다. |
| `accel_time` | 0.25 | 0~5 | 시작할 때 속도가 붙는 시간(초). 올리면 무겁게 출발하고, 0이면 즉시 최고 속도입니다. |
| `slide_cells` | 3.0 | 0.5~12 | 감속해서 미끄러지는 거리(칸). 올리면 길고 부드럽게 미끄러지고, 내리면 딱 멈추는 느낌입니다. |
| `slide_ease_power` | 3.0 | 1~8 | 감속 곡선의 꼬리. 올리면 끝에서 천천히 기어가듯 멈추고 전체 시간도 길어집니다. 1이면 일정하게 느려집니다. |
| `bounce_cells` | 0.15 | 0~1 | 목표를 살짝 지나쳤다가 돌아오는 거리(칸). 0이면 튕김이 없습니다. |
| `bounce_time` | 0.14 | 0~2 | 튕겨 돌아오는 시간(초). 늘리면 느릿하게 돌아옵니다. |
| `reel_start_delay` | [0, 0.08, 0.16] | 각 0~0.5 | 릴1·2·3이 START 후 출발하는 시각(초). 늘리면 릴이 더 확연히 차례로 출발합니다. 이 값은 `auto_stop_start`보다 작아야 하며, 아니면 기본값으로 대체됩니다. |
| `reel_speed_scale` | [1.0, 0.95, 1.05] | 각 0.5~1.5 | 릴1·2·3의 회전 속도 배율(`spin_speed`에 곱함). 릴마다 다르게 하면 서로 다른 속도로 도는 것이 보입니다. 모두 1.0이면 속도차 없음. |
| `auto_stop_start` | 3.0 | 0~60 | 안 누르면 START 후 몇 초에 첫 릴(왼쪽)이 멈추기 시작할지. |
| `auto_stop_interval` | 0.4 | 0~10 | 자동 정지 때 릴 사이 간격(초). |
| `quick_stop_interval` | 0.15 | 0~5 | 회전 중 START를 눌렀을 때 남은 릴이 차례로 멈추기 시작하는 간격(초). |
| `start_lock_sec` | 0.3 | 0~5 | START 직후 이 시간 동안은 START 재입력(스페이스 연타)을 무시합니다. |
| `result_delay` | 0.25 | 0~5 | 마지막 릴이 멈춘 뒤 정산·당첨 연출이 시작되기까지의 간격(초). |

## 실행 중에 바꾸기

게임을 켜 둔 채로 `data/feel.json`을 고치고 **저장**하면 0.5초 안에 자동으로 다시 읽습니다. 바로 읽게 하려면 **F6**을 누르세요.
읽었다는 안내가 아래 안내 문구에 나옵니다.

- **적용은 다음 START부터**입니다. 돌고 있는 스핀은 시작할 때의 수치로 끝까지 갑니다.
- 결과(어떤 심볼이 서는지)는 START 때 이미 정해져 있어서 수치를 바꿔도 달라지지 않습니다.
- 모든 항목이 다음 START부터 적용됩니다 (재시작이 필요한 항목은 없습니다).
- 출발 시각은 **START 기준**이고, 자동 정지 시각(`auto_stop_start` 등)도 START 기준입니다. 출발 지연은 늦게 출발하는 릴의 회전 시간만 줄이고 정지 순서는 바꾸지 않습니다.
- 아직 출발하지 않은 릴은 STOP 버튼이 꺼져 있고(출발하면 켜짐), 회전 중 START를 누르면 출발 전인 릴도 같은 순서로 예약되어 출발 직후 멈춥니다.
- 파일이 저장되던 도중이라 JSON이 깨져 읽을 수 없으면 **이전 값을 유지**하고 그렇게 안내합니다.
- 숫자가 범위를 벗어난 항목은 그 항목만 기본값으로 대체하고 안내에 표시합니다.
- 개발 중 F5 실행에서만 동작합니다 (게임을 내보낸 파일에서는 `res://` 파일을 고칠 수 없음).

## 알아둘 점: STOP을 누른 뒤 멈추기까지의 대기

결과가 이미 정해져 있어서, 릴은 "정해진 위치가 감속 구간 앞에 올 때"까지 같은 속도로 더 돈 다음 감속합니다.
그래서 STOP을 누른 뒤 멈추기까지 걸리는 시간은 그때그때 다르고, 최대는 한 바퀴 도는 시간 + 감속 시간입니다.

- 최대 대기 ≈ `릴 길이(32칸) ÷ spin_speed` + 감속 시간 (기본값이면 약 1.2초 + 0.5초)
- 평균은 그 절반쯤입니다.
- 반응이 굼뜨게 느껴지면 `spin_speed`를 올리는 것이 가장 효과가 큽니다. `slide_cells`를 줄이면 감속 구간이 짧아져 "딱" 멈추지만, 대기 시간 자체는 크게 안 줄어듭니다.

## 이런 느낌을 원할 때

| 원하는 느낌 | 이렇게 |
|---|---|
| 묵직하게 천천히 도는 릴 | `spin_speed` 18, `accel_time` 0.4 |
| 빠르고 경쾌하게 | `spin_speed` 40, `accel_time` 0.15, `slide_cells` 2 |
| 딱딱 끊어 멈추는 오락실 느낌 | `slide_cells` 1.5, `slide_ease_power` 2, `bounce_cells` 0.1 |
| 미끄러지듯 길게 | `slide_cells` 5, `slide_ease_power` 4 |
| 튕김 없이 깔끔하게 | `bounce_cells` 0 |
