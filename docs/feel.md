# 손맛 조절 안내 (`data/feel.json`)

릴이 돌고 멈추는 느낌을 바꾸는 수치 모음입니다. 파일을 고치고 게임을 다시 실행(F5)하면 바로 적용됩니다.
**결과(어떤 심볼이 서는지)는 이 수치와 무관합니다.** 결과는 START 순간에 정해지고, 이 수치는 "어떻게 보여주느냐"만 바꿉니다.

범위를 벗어나거나 숫자가 아닌 값을 넣으면 그 항목만 기본값으로 대체되고, 실행 로그에 경고가 남습니다. 게임이 꺼지지는 않습니다.
`reel_start_delay`·`reel_speed_scale`은 릴 3개 분량의 목록(`[릴1, 릴2, 릴3]`)입니다. 개수가 다르거나 하나라도 범위 밖이면 목록 전체가 기본값으로 대체됩니다.
(예전 `half_row` 항목은 칸 단위 창 방식으로 바뀌며 없어졌습니다. 파일에 남아 있어도 무시됩니다.)

| 키 | 기본값 | 범위 | 올리면 / 내리면 |
|---|---|---|---|
| `spin_speed` | 26 | 1~200 | 칸/초. 올리면 빨리 돌고, STOP 후 멈추기까지의 최대 대기도 짧아집니다. 너무 높으면 심볼이 번쩍거려 읽기 어렵습니다. |
| `accel_time` | 0.25 | 0~5 | 시작할 때 속도가 붙는 시간(초). 올리면 무겁게 출발하고, 0이면 즉시 최고 속도입니다. |
| `slide_cells` | 3.0 | 0.5~12 | 감속해서 미끄러지는 거리(칸). 올리면 길고 부드럽게 미끄러지고, 내리면 딱 멈추는 느낌입니다. |
| `slide_ease_power` | 3.0 | 1~8 | 감속 곡선의 꼬리. 올리면 끝에서 천천히 기어가듯 멈추고 전체 시간도 길어집니다. 1이면 일정하게 느려집니다. |
| `bounce_cells` | 0.15 | 0~1 | 목표를 살짝 지나쳤다가 돌아오는 거리(칸). 0이면 튕김이 없습니다. |
| `bounce_time` | 0.14 | 0~2 | 튕겨 돌아오는 시간(초). 늘리면 느릿하게 돌아옵니다. |
| `reel_start_delay` | [0, 0.08, 0.16] | 각 0~0.5 | 릴1·2·3이 START 후 출발하는 시각(초). 늘리면 릴이 더 확연히 차례로 출발합니다. 이 값은 `auto_stop_start`보다 작아야 하며, 아니면 기본값으로 대체됩니다. |
| `reel_speed_scale` | [1.0, 0.95, 1.05] | 각 0.5~1.5 | 릴1·2·3의 회전 속도 배율(`spin_speed`에 곱함). 릴마다 다르게 하면 서로 다른 속도로 도는 것이 보입니다. 모두 1.0이면 속도차 없음. |
| `auto_stop_start` | 3.0 | 0~60 | 안 누르면 START 후 몇 초에 첫 릴(왼쪽)이 멈추기 시작할지. |
| `auto_stop_interval` | 0.4 | 0~10 | 자동 정지 때 릴 사이 간격(초). |
| `quick_stop_interval` | 0.15 | 0~5 | 회전 중 START를 눌렀을 때 남은 릴이 차례로 멈추기 시작하는 간격(초). |
| `start_lock_sec` | 0.3 | 0~5 | START 직후 이 시간 동안은 START 재입력(스페이스 연타)을 무시합니다. |
| `result_delay` | 0.25 | 0~5 | 마지막 릴이 멈춘 뒤 정산·당첨 연출이 시작되기까지의 간격(초). |
| `auto_spin_gap_sec` | 0.5 | 0~10 | AUTO를 켰을 때 한 판이 정산된 뒤(피버·풀 연출이 끝난 뒤) 다음 판을 자동으로 시작하기까지의 대기시간(초). 다음 스핀부터 적용됩니다. |
| `fever_overlay_sec` | 2.0 | 0.2~10 | 피버 오버레이에서 심볼 하나를 보여 주는 시간(초). 피버가 둘 이상이면 심볼마다 이 시간씩 차례로 보여 줍니다. |
| `fever_step_gap` | 0.3 | 0~5 | 피버 심볼과 심볼 사이 빈 간격(초). 심볼이 하나면 쓰이지 않습니다. |
| `fever_skip_lock_sec` | 0.4 | 0~5 | 오버레이가 뜬 직후 이 시간 동안은 스페이스 건너뛰기를 무시합니다(연타로 바로 넘어가는 것 방지). |
| `pool_overlay_sec` | 3.0 | 0.2~10 | 세븐 피버로 풀을 획득할 때 "POOL GET!" 화면에서 풀 금액을 보여 주는 시간(초). 세븐 피버 화면 바로 뒤에 한 번 나오며, 사이 간격은 `fever_step_gap`을 씁니다. |
| `pool_yellow_from` | 1000 | 0~10억 | POOL 숫자가 이 값 이상이면 주황 → 노랑. 반드시 `pool_red_from`보다 작아야 하며, 아니면 두 값 모두 기본값으로 대체됩니다. |
| `pool_red_from` | 1500 | 0~10억 | POOL 숫자가 이 값 이상이면 빨강으로 바뀌고 가볍게 깜빡입니다. |
| `win_mid_ratio` | 2.0 | 0.1~1000 | 당첨 효과음 "중"이 나오는 기준: (총 지급 ÷ 총 베팅)이 이 값 이상이면 중. 미만은 소. `win_big_ratio`보다 작아야 하고, 아니면 둘 다 기본값을 씁니다. 피버·풀 연출이 있을 때는 이 소리 대신 연출 소리가 납니다. |
| `win_big_ratio` | 10.0 | 0.1~1000 | 당첨 효과음 "대"가 나오는 기준: (총 지급 ÷ 총 베팅)이 이 값 이상이면 대. |
| `sfx_volume_db` | 0.0 | -40~6 | 효과음 전체 볼륨(dB). 0이 원래 크기, -6이면 약 절반. 다음 스핀부터 적용됩니다. |
| `bgm_volume_db` | -12.0 | -40~6 | BGM 전체 볼륨(dB). 두 곡 모두 음량이 커서 기본 -12. 다음 스핀부터 적용됩니다. |
| `bgm_to_fever_sec` | 0.3 | 0~5 | 피버 연출이 시작될 때 메인 BGM에서 피버 BGM으로 바뀌는 시간(초). 메인은 멈춘 자리를 기억합니다. |
| `bgm_to_main_sec` | 1.0 | 0~5 | 피버가 끝나고 메인 BGM(멈춘 자리부터)으로 돌아오는 시간(초). 게임을 켰을 때 메인 BGM이 서서히 커지는 시간도 이 값입니다. |
| `bgm_loop_trim_sec` | 2.0 | 0~10 | BGM이 끝나기 이만큼(초) 전에 같은 곡을 처음부터 다시 틀어서, 곡 끝의 페이드아웃과 무음 구간 없이 이어지게 합니다. |
| `bgm_loop_fade_sec` | 1.0 | 0~5 | BGM 반복 때 이전 소리가 줄고 새 소리가 커지는 시간(초). `bgm_loop_trim_sec`보다 크면 둘 다 기본값을 씁니다. |
| `bulb_idle_sec` | 0.8 | 0.1~5 | 대기 중 보드 전구 링과 프레임 소켓이 짝수/홀수로 번갈아 깜빡이는 주기(초). 클수록 천천히 깜빡입니다. |
| `bulb_spin_step_sec` | 0.06 | 0.01~1 | 릴이 도는 동안 켜진 전구가 한 칸 도는 시간(초). 작을수록 빨리 돕니다. |
| `bulb_win_flash_sec` | 0.12 | 0.02~1 | 당첨 때 전구가 전부 켜졌다 꺼지는 번쩍임의 간격(초). 당첨선 깜빡임이 끝날 때까지 이어집니다. |
| `bulb_fever_sec` | 0.2 | 0.02~2 | 피버·풀 정산 때 전구가 노랑↔빨강으로 바뀌는 간격(초). 연출 오버레이가 보드를 가리므로 오버레이가 끝난 직후에 보입니다. |

### 정산 연출 (6-F3b)

당첨이 나오면 WIN 숫자가 0에서 올라가고, 동전이 WIN 칸에서 CREDIT 칸으로 날아가 도착할 때마다 CREDIT이 오릅니다. 당첨 크기(소/중/대)는 `win_mid_ratio`·`win_big_ratio` 기준을 따릅니다.
START를 누르면 연출을 끝내고 숫자를 최종값으로 확정한 뒤 바로 다음 판을 시작합니다. AUTO 대기시간은 이 연출이 끝난 뒤부터 셉니다.

| 키 | 기본값 | 범위 | 뜻 |
|---|---|---|---|
| `countup_small_sec` | 0.6 | 0.05~10 | 소 당첨: WIN 숫자가 0에서 최종값까지 올라가는 시간(초) |
| `countup_mid_sec` | 1.2 | 0.05~10 | 중 당첨의 카운트업 시간(초) |
| `countup_big_sec` | 2.5 | 0.05~10 | 대 당첨의 카운트업 시간(초) |
| `countup_tick_sec` | 0.05 | 0.02~0.5 | 카운트업 중 틱 소리의 최소 간격(초). 작을수록 촘촘하게 "따다다닥" |
| `coin_count_small` | 3 | 1~40 | 소 당첨 때 날아가는 동전 개수. 당첨금보다 많으면 당첨금만큼으로 줄어듭니다 |
| `coin_count_mid` | 6 | 1~40 | 중 당첨의 동전 개수 |
| `coin_count_big` | 12 | 1~40 | 대 당첨의 동전 개수 |
| `coin_fly_sec` | 0.45 | 0.05~3 | 동전 한 개가 WIN 칸에서 CREDIT 칸까지 날아가는 시간(초) |
| `auto_effect_scale` | 0.5 | 0.1~1 | AUTO 중 카운트업·동전 시간에 곱하는 배율. 1이면 AUTO도 같은 속도, 작을수록 AUTO가 빨라집니다 |

- 전체 연출 시간 = 카운트업 시간 + 동전 비행 시간. 동전은 카운트업이 진행되는 동안 일정 간격으로 출발하고, 마지막 동전은 카운트업이 끝나는 순간 출발합니다.
- 피버·풀 정산 직후의 피버 전구 모양(`bulb_fever_sec` 교대)은 이 전체 연출 시간 동안 이어집니다.

### GAME OVER (7-B)

크레딧이 0이 되면 GAME OVER 화면이 뜹니다. 화면이 뜨는 시점과 입력 잠금, BGM 페이드만 이 수치로 바꿉니다. 시작 크레딧·CONTINUE 금액·횟수는 `data/economy.json`에서 바꿉니다.

| 키 | 기본값 | 범위 | 뜻 |
|---|---|---|---|
| `gameover_delay_sec` | 0.8 | 0~5 | 크레딧이 0이 된 판의 연출(정산·피버·풀)이 모두 끝난 뒤 GAME OVER 화면이 뜨기까지의 간격(초). 꽝 판을 잠깐 보여 주는 시간입니다 |
| `gameover_input_lock_sec` | 0.5 | 0~3 | 화면이 뜬 직후 이 시간 동안은 스페이스·엔터·클릭을 무시합니다(연타로 바로 눌리는 것 방지) |
| `bgm_gameover_fade_sec` | 0.5 | 0~5 | GAME OVER 동안 BGM이 줄며 멈추는 시간, CONTINUE·NEW GAME 때 멈춘 자리부터 다시 커지는 시간(초) |

## 실행 중에 바꾸기

게임을 켜 둔 채로 `data/feel.json`을 고치고 **저장**하면 0.5초 안에 자동으로 다시 읽습니다. 바로 읽게 하려면 **F6**을 누르세요.
읽었다는 안내가 아래 안내 문구에 나옵니다.

- **적용은 다음 START부터**입니다. 돌고 있는 스핀은 시작할 때의 수치로 끝까지 갑니다.
- 결과(어떤 심볼이 서는지)는 START 때 이미 정해져 있어서 수치를 바꿔도 달라지지 않습니다.
- 모든 항목이 다음 START부터 적용됩니다 (재시작이 필요한 항목은 없습니다).
- 출발 시각은 **START 기준**이고, 자동 정지 시각(`auto_stop_start` 등)도 START 기준입니다. 출발 지연은 늦게 출발하는 릴의 회전 시간만 줄이고 정지 순서는 바꾸지 않습니다.
- 아직 출발하지 않은 릴은 STOP 버튼이 꺼져 있고(출발하면 켜짐), 회전 중 START를 누르면 출발 전인 릴도 같은 순서로 예약되어 출발 직후 멈춥니다.
- 파일이 저장되던 도중이라 JSON이 깨져 읽을 수 없으면 **이전 값을 유지**하고 그렇게 안내합니다.
- 숫자가 범위를 벗어난 항목은 그 항목만 기본값으로 대체하고 안내에 표시합니다.
- 개발 중 F5 실행에서만 동작합니다 (게임을 내보낸 파일에서는 `res://` 파일을 고칠 수 없음).

## 알아둘 점: STOP을 누른 뒤 멈추기까지의 대기

결과가 이미 정해져 있어서, 릴은 "정해진 위치가 감속 구간 앞에 올 때"까지 같은 속도로 더 돈 다음 감속합니다.
그래서 STOP을 누른 뒤 멈추기까지 걸리는 시간은 그때그때 다르고, 최대는 한 바퀴 도는 시간 + 감속 시간입니다.

- 최대 대기 ≈ `릴 길이(32칸) ÷ spin_speed` + 감속 시간 (기본값이면 약 1.2초 + 0.5초)
- 평균은 그 절반쯤입니다.
- 반응이 굼뜨게 느껴지면 `spin_speed`를 올리는 것이 가장 효과가 큽니다. `slide_cells`를 줄이면 감속 구간이 짧아져 "딱" 멈추지만, 대기 시간 자체는 크게 안 줄어듭니다.

## 이런 느낌을 원할 때

| 원하는 느낌 | 이렇게 |
|---|---|
| 묵직하게 천천히 도는 릴 | `spin_speed` 18, `accel_time` 0.4 |
| 빠르고 경쾌하게 | `spin_speed` 40, `accel_time` 0.15, `slide_cells` 2 |
| 딱딱 끊어 멈추는 오락실 느낌 | `slide_cells` 1.5, `slide_ease_power` 2, `bounce_cells` 0.1 |
| 미끄러지듯 길게 | `slide_cells` 5, `slide_ease_power` 4 |
| 튕김 없이 깔끔하게 | `bounce_cells` 0 |

## 운영자 설정이 feel.json 위에 덮어쓰는 값 (8-A)

시작 화면에서 **F2**를 눌러 여는 운영자 설정 화면은 아래 feel 키를 바꿀 수 있습니다. 바꾼 값은 `data/feel.json`이 아니라 **`user://settings.json`에 저장**되고, 게임을 켤 때 feel.json 값 위에 덮어씁니다.

| 설정 화면 줄 | feel 키 |
|---|---|
| 효과음 볼륨 / BGM 볼륨 | `sfx_volume_db` / `bgm_volume_db` |
| AUTO 연출 배율 | `auto_effect_scale` |
| 정산 연출 소 / 중 / 대 (초) | `countup_small_sec` / `countup_mid_sec` / `countup_big_sec` |
| 당첨 중 / 대 기준 (배) | `win_mid_ratio` / `win_big_ratio` (중 < 대) |

**주의: 설정 파일에 저장된 키는 feel.json(·economy.json)을 고쳐도 반영되지 않습니다.**
- 설정 화면에서 기본값과 다른 값은 **노랑**으로 보입니다. 노랑인 줄이 곧 "설정 파일에 저장된 키"입니다.
- **바꾸지 않은 키는 feel.json을 고치면 계속 반영**됩니다 (설정 파일에는 바꾼 키만 저장되고, 기본값으로 돌아오면 저장 대상에서 빠집니다).
- F6·파일 감시로 feel.json을 다시 읽어도 설정 키의 덮어쓰기는 유지됩니다.
- 같은 방식으로 economy.json의 `start_credit` / `continue_credit` / `continue_max` / `coin_amount`와 balance.json의 `auto_spin.stop_on_win_at`도 설정 화면에서 덮어쓸 수 있습니다. 밸런스(릴·배당·피버·풀)는 설정 화면에 없습니다.
- `bgm_enabled`(BGM 켜기/끄기)는 설정 파일에만 있는 키입니다 (data/*.json에는 없음, 기본 켜짐).

| 파일 | 내용 | Windows 실제 경로 |
|---|---|---|
| `settings.json` | 운영자가 바꾼 설정 (`{"version":1,"values":{...}}`, 바꾼 키만) | `%APPDATA%\Godot\app_userdata\FruitSlot\settings.json` (예: `C:\Users\<사용자>\AppData\Roaming\Godot\app_userdata\FruitSlot\`) |
| `highscore.json` | 최고 기록 (`{"version":1,"best_peak_credit":숫자}`) | 같은 폴더의 `highscore.json` |

- 에디터에서 폴더를 바로 여는 방법: **프로젝트 → 사용자 데이터 폴더 열기**. 내보낸 exe도 프로젝트 이름(`FruitSlot`)이 같아 같은 폴더를 씁니다.
- 파일이 없거나 망가졌거나 버전을 모르면 **기본값(feel.json·economy.json·balance.json)으로 시작**합니다 (망가진 파일은 다음 "저장하고 닫기" 전까지 건드리지 않음). 범위 밖 값과 모르는 키는 그 키만 무시합니다.

### 기본값으로 되돌리는 방법
1. 시작 화면에서 **F2** → 하단 **"기본값으로"**를 **두 번** 누르면(첫 클릭은 확인 글자로만 바뀜) 설정 값 전체가 기본값으로 돌아갑니다 → **"저장하고 닫기"**로 확정. 최고 기록은 그대로 남습니다.
2. 또는 게임을 끄고 `settings.json`을 삭제해도 됩니다 (다음 실행부터 전부 기본값).
3. 최고 기록은 크레딧 탭의 **"최고 기록 초기화"**(두 번 클릭) 또는 `highscore.json` 삭제로 지웁니다.
