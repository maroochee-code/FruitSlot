# Windows 릴리스 exe 내보내기

목적: 본인 PC에서 실행해 보는 릴리스 exe 1개 (배포용 아님). 프리셋은 저장소 루트 `export_presets.cfg`, 결과물은 `builds/FruitSlot.exe`(`.gitignore`로 제외).

## 준비 (한 번만)
- Godot 4.7.2 내보내기 템플릿 설치: `%APPDATA%\Godot\export_templates\4.7.2.stable\` 안에 `windows_release_x86_64.exe`가 있어야 한다.
- 프로젝트를 한 번 가져오기(import) 해 둔다 (`godot --headless --path . --import`).

## 내보내기 명령
```
Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release "Windows Desktop" builds/FruitSlot.exe
```
- **반드시 `--export-release`(릴리스 템플릿)로 내보낸다.** 에디터의 "디버그와 함께 내보내기"를 켜면 디버그 템플릿이 되어 `OS.is_debug_build()`가 true가 되고 개발 기능(COIN·테스트 모드·DEV 라벨)이 켜진다.
- 결과: exe 1개(pck 내장, 약 118MB).

## 프리셋 요약
| 항목 | 값 |
|---|---|
| 포함 필터 | `data/*.json` (json은 리소스가 아니라서 필수: balance·feel·economy) |
| 제외 필터 | `scenes/test/*`, `tools/*`, `docs/*`, `assets/_preview/*`, `CHANGELOG.md`, `CLAUDE.md` |
| 포함되는 것 | 스크립트(`TestMenu` 포함 — 릴리스에서는 만들어지지 않음), 씬(title·main), 폰트·wav·mp3·png |
| 콘솔 창 | 없음 |
| exe 아이콘·버전 정보 | 넣지 않음(`application/modify_resources=false`). 넣으려면 rcedit와 `.ico`가 필요 |

## 릴리스에서 막히는 개발 기능 (`GameState.dev_build = OS.is_debug_build()`)
COIN(C 키·버튼), 테스트 모드(F3 토글·테스트 메뉴·TEST 라벨·결과 강제), DEV·TEST MODE 라벨, 설정 화면의 COIN 지급량 줄, COIN 안내 문구, **F1(디버그 창)·F6(feel 재로딩)**. **F2(운영자 설정)는 릴리스에서도 열린다.**

## 저장 위치
`%APPDATA%\Godot\app_userdata\FruitSlot\` 의 `settings.json`, `highscore.json`. **에디터(F5) 실행과 exe가 같은 폴더를 쓴다.** `config/name`을 바꾸면 이 폴더 이름도 바뀐다.

## exe 확인 체크리스트
1. 시작 화면: DEV·TEST MODE 라벨 없음, `BEST` 표시(기록이 있으면)
2. **F2** → 설정 열림, 크레딧 탭에 COIN 지급량 줄 없음, Esc는 설정만 닫음
3. **F3** 무반응, **F1·F6** 무반응, 게임 화면에서 C 무반응·COIN 버튼 회색·TEST 라벨 없음·안내 "크레딧이 부족합니다."
4. START → 플레이(START / STOP ALL / SKIP 글자, 피버·풀·동전 회전)
5. F2에서 값 변경 → 저장 → 종료 후 재실행해도 유지
6. GAME OVER → CONTINUE / NEW GAME, 창 X로 닫고 다시 켜서 `BEST` 확인
7. 시작 화면 Esc로 종료
