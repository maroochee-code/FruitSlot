### 가정
1. 라벨 위치: 가로·대각선은 시작 칸 높이의 왼쪽 + 끝 칸 높이의 오른쪽(같은 높이는 위아래로 쌓음), 세로(F·G·H)는 각 릴 위쪽에만 둔다 (아래쪽은 STOP 자리와 겹쳐 생략).

5. WIN은 START 순간 0으로 지워지고 스핀 결과의 총 당첨금으로 채워진다.

4. 한글 글꼴은 시스템 글꼴(맑은 고딕 우선)을 쓴다. 웹 내보내기 단계에서는 글꼴 파일을 프로젝트에 넣어야 할 수 있다(확인 필요).
5. 디버그 창은 오른쪽 패널 위에 겹쳐 그린다(기본 켜짐). 끄면 3단계 자리(POOL·피버)가 보인다.
6. 라인 라벨 자리는 릴 좌우에 4칸씩, 위치는 임시다. 3단계에서 각 라인 끝 위치에 맞춰 조정한다.

### 가정 (기획서에 명시되지 않아 정한 것)
1. 정지 위치 = 윗줄에 보이는 스트립 번호. 가운데 +1, 아랫줄 +2, 끝에서 처음으로 이어짐.
2. 피버 보너스의 "현재 총 베팅" = 피버가 발동한 스핀의 총 베팅.
3. 한 스핀에 피버 대상 심볼 여러 개가 당첨되면 각 심볼 카운터가 1씩 줄어든다.
4. 피버는 그 스핀에서 바로 판정·지급한다 (로직 확정, 화면은 정지 후 보여주기만).
5. 풀 적립은 베팅액과 관계없이 매 스핀. 획득만 BET 8 이상.
6. 풀 소수점(8 × 5% = 0.4)은 내부에서 누적하고, 표시·지급은 정수(버림). 획득 후 500으로 리셋(소수점도 버림).
7. 처리 순서: 풀 적립 → 라인 판정 → 피버 → (세븐 피버면) 풀 획득.
8. RTP = (라인 당첨 + 피버 보너스 + 풀 지급) ÷ 총 베팅.
9. 시뮬레이션은 크레딧 부족을 따지지 않는다.
10. 릴 스트립: 3칸 연속은 릴마다 체리·오렌지 1곳씩만, 나머지 심볼은 최대 2칸 연속.
